本阶段的需求摘要
已打通了异步导出任务的前后端请求，本阶段在前端加入“导出中心”的模块。

修复 bug
- 订单管理模块
    1. 表格区域分页器会把最后一条数据挡住了
    2. 筛选条件默认是按照创建时间的降序排列



本阶段目标

1. 前端页面搭建
  - 基于订单管理的样式，全页面不滚动，顶部有 title 标题“导出中心”，同一行的右侧，提供 tab 切换，包括4个状态机的状态切换，加上全部。（暂不提供按钮操作）
  - 表格区域滚动，底部有分页器
  - 表格的表头对应：
      1. 任务编号
      2. 文件名
      3. 导出范围:（描述当前导出任务选择的模式）
      4. 导出统计条数
      5. 导出实际条数
      6. 状态（对应状态机）
      7. 进度（使用百分比结合 progress 组件）
      8. 创建时间
      9. 完成时间
      10. 文件大小

2. 后端提供导出中心接口
  - 基于 restful 的形式，复用 /export-job 接口（严格遵循MVC分层进行文件目录创建）
  - 数据查询与 export_jobs 表，返回数据默认按照创建时间降序排列
